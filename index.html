03 · Research

Selected vulnerability disclosures

Valid findings reported through bug bounty programs. Targets, hosts and paths are removed; each write-up keeps only the vulnerability class, impact and fix.

CVSS 9.8 · Critical

Unauthenticated remote code execution on registry infrastructure

CWE-434 · Domain registry

An exposed, unpatched CMS file-manager connector allowed unauthenticated file upload and execution, leading to full server takeover. Reported during active exploitation in the wild; emergency patched.

Fix: remove the connector from production, enforce authentication and upload allow-lists, patch the CMS.

CVSS 8.2 · High

Anonymous content-repository query exposing 66,000+ internal nodes

CWE-284 · Global retail enterprise

A misconfigured Adobe Experience Manager dispatcher left the query endpoint open to anonymous users, exposing unreleased campaign material and metadata across 6,800+ files.

Fix: block query endpoints at the dispatcher and remove anonymous read permissions on the repository.

CVSS 7.6 · High

Session and refresh tokens leaked in URLs, leading to account takeover

CWE-598 · Event & community SaaS

Live access and refresh JWTs were passed as URL query parameters during redirects, leaking into browser history, proxy logs and Referer headers. Replaying the URL took over the account.

Fix: move tokens to secure, HttpOnly cookies or a POST body; shorten token lifetime and rotate refresh tokens.

CVSS 7.2 · High

GraphQL authorization flaws: unauthorized spending and admin email change

CWE-284 / CWE-840 · Benefits SaaS

Role checks were missing on GraphQL mutations, so HR-only admins could spend company credit and change the primary admin's email address without re-authentication.

Fix: enforce authorization per mutation on the server, and require re-authentication for identity changes.

CVSS 6.5 · Medium

Checkout logic flaw allowing forced stock depletion

CWE-840 · Luxury e-commerce

Guest cash-on-delivery orders with unverified phone numbers and no velocity limits reduced live warehouse stock, letting an attacker sell out products during campaigns.

CVSS 6.2 · Medium

HTML injection in transactional email (plus a patch bypass)

CWE-94 · Event SaaS · rewarded twice

Unconfirmed profile fields were rendered into magic-link emails, so phishing links went out from a trusted sender. The first fix was bypassed with encoded payloads.

CVSS 5.3 · Medium

Token-binding failure and IDOR on a bank callback API

CWE-639 · Canadian financial institution

The proof-of-CAPTCHA token was not bound to the customer record, so captured tokens could be replayed to book fraudulent call-back requests.

CVSS 4.1 · Medium

No-op updates triggering outbound email amplification

CWE-799 · Security platform

Settings updates that changed nothing still sent notification emails, with no rate limit, allowing email flooding from a trusted domain.

All write-ups follow each program's disclosure rules.
